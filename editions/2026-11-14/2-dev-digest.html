Node / MERN & Python backends

Node.js 27 alpha: V8 15.6, Iterator.zip, Math.sumPrecise — and a bigger default heap

Node.js blog · Nov 5 & Nov 12, 2026

The first Node.js 27 alpha (Nov 12) upgrades V8 from 14.6 to 15.6 (notes published Nov 5). New on-by-default JS features include Math.sumPrecise(), Iterator.zip/zipKeyed and iterator join/includes. Sorting uses PowerSort instead of TimSort for larger arrays.

💡 Why it matters to you: Your MERN projects aren't affected yet (27 is alpha), but the V8 notes are a free “what's coming in JavaScript” tutorial.
Read deeper

Potential breakers: Math function last-bit differences, Math.random() sequences for a given seed, error.stack no longer read through the prototype chain, new structured-clone serialization that Node 26 and older cannot read, and a default old-generation limit of half of RAM (clamped 256 MB–4 GB) on 4–15 GB machines — so an 8 GB host now gets 4 GB. Set --max-old-space-size explicitly if you relied on the old limit.

asm.js is no longer compiled to WebAssembly, and Debugger.setScriptSource is removed.

[0.1, 0.2, 0.3].reduce((a, b) => a + b); // 0.6000000000000001
Math.sumPrecise([0.1, 0.2, 0.3]);        // 0.6

Iterator.zipKeyed({ id: [1, 2], name: ['a', 'b'] }).toArray();
// [{ id: 1, name: 'a' }, { id: 2, name: 'b' }]

Security

Node.js patches 16 vulnerabilities (7 High) across 22.x, 24.x and 26.x

Node.js blog · Nov 11, 2026

The Nov 11 security releases — v22.23.5, v24.22.3 and v26.13.1 — fix 16 CVEs: 7 High, 6 Medium and 3 Low, mostly in HTTP/2 and TLS, plus updated llhttp, undici and sqlite. End-of-life lines are also affected.

💡 Why it matters to you: Any Express/Socket.IO server in production should be on these builds today — especially if it terminates HTTPS/HTTP2 itself.
Read deeper

Highlights: CVE-2026-123863 (unauthenticated HTTP/2 remote crash, 24.x/26.x), CVE-2026-123864 (HTTPS use-after-free that can leak server heap including TLS keys), CVE-2026-123872 (TLS 1.2 client-cert auth bypass via servername change during renegotiation), CVE-2026-123867 (mTLS bypass with a CA-only SNI context) and CVE-2026-123871 (proxy credentials exposed in error messages and logs).

If you run behind nginx or a cloud load balancer that terminates TLS, exposure is smaller, but still patch. Rebuild Docker images — updating the host Node isn't enough.

node --version        # want >= 22.23.5 / 24.22.3 / 26.13.1
docker build --pull --no-cache -t myapp .
