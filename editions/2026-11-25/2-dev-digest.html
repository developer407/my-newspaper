Spring Security 7.2.0: workflow read permissions, CSP nonces on login and passkey pages

Spring Security 7.2.0 lets you declare read permissions at the workflow top level, fixes CSP nonce support on the default login and passkey registration pages, and upgrades Spring Framework to 7.1.0, Micrometer to 1.18.0 and Reactor to 2026.0.0. Spring Batch 6.1: @JobParameter, a type-safe PageableItemReader and much cheaper restarts

Spring blog · Nov 19, 2026

Spring Batch 6.1 adds a @JobParameter annotation replacing the SpEL jobParameters lookup, a type-safe PageableItemReader, location patterns for resource readers, a collection prefix for the MongoDB job repository, and JsonLineMapper and JsonLineAggregator. Restarts only check the last execution, and listing executions drops from 1 + 3N queries to 2.

💡 Why it matters to you: Spring Batch is the natural home for scheduled AI jobs such as re-embedding documents; the partition-count fix cut memory about tenfold in one reported case with 837 partitions.
Read deeper

Breaking changes: builder return types changed (source and binary incompatible), Avro reflection now needs explicitly trusted types, JDBC DAO no-arg constructors were removed. Derby support and the integration-module async classes are deprecated.

It builds on Spring Framework 7.1.0, Spring Data 2026.1.0 and Kafka 4.2.0, so move to Boot 4.2 together.

@Bean @StepScope
FlatFileItemReader<Foo> fooReader(@JobParameter String inputFile) {
  return new FlatFileItemReaderBuilder<Foo>()
      .resource(new FileSystemResource(inputFile)).build();
}

Pydantic AI 2.74.0 closes six PlaywrightBrowser egress advisories and adds a ComputerTool

Pydantic AI GitHub releases · Nov 24, 2026

Pydantic AI 2.74.0 fixes six advisories in PlaywrightBrowser (IPv6 site-local and NAT64 bypasses, a backslash-in-URL host bypass, and WebRTC, WebTransport and WebSocketStream egress gaps) and a leak of secret__ dynamic variables in ElevenLabs trace spans. It also adds core ComputerTool support and a DeprecatedModelWarning for claude-opus-4-5. A 1.107.11 backport fixes OpenTelemetry baggage setting evaluation attributes.

💡 Why it matters to you: If you run browser-using agents behind FastAPI, upgrade: the egress policy is what stops an agent from being talked into fetching internal URLs.
Read deeper

Under the default enforced egress policy, PlaywrightBrowser pages lose RTCPeerConnection, WebTransport, WebSocketStream and FedCM, so a page that relied on them will break. Streamed Gemini usage through OpenAIChatModel is no longer summed.

The prior 2.73.0 (Nov 24) added SubAgents passing deferred tool calls to the caller and raised the openai floor to 3.50.0, and its DeprecatedModelWarning now fires for deprecated Anthropic and OpenAI models.

pip install -U "pydantic-ai==2.74.0"
