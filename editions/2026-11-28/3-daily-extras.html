AI tools of the day

Tool: last30days, an agent skill that researches a topic across Reddit, X, YouTube, Hacker News and more

GitHub, mvanhorn/last30days-skill · about 76.4k stars, MIT license

last30days is an agent skill that takes a topic, such as a product or "X vs Y", finds the relevant handles, subreddits and channels, and searches all enabled sources in parallel. It pulls deeper content such as YouTube transcripts and top Reddit comments, merges duplicate stories into clusters, ranks by engagement and writes a cited brief.

💡 Why it matters to you: This is a ready-made "what did people say in the last 30 days" research step for your tutorial planning. It also shows how a skill can wrap a whole multi-source workflow.
Read deeper

Reddit, Hacker News, Polymarket and GitHub work without configuration. Sources such as X and YouTube need API keys or local tools, and a setup wizard helps with that. Check what keys it asks for before you run it on a work machine.

Install it as a Claude Code plugin or through the Agent Skills CLI, which also covers Codex, Cursor, Copilot and Gemini CLI.

# Claude Code
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days

# Other Agent Skills hosts
npx skills add mvanhorn/last30days-skill -g

Tool: diagram-design, a skill that draws 52 kinds of diagrams as a single self-contained HTML and SVG file

GitHub, cathrynlavery/diagram-design · about 74.5k stars, MIT license

You describe a diagram in plain language, and the agent picks a type and writes one .html file you can open in a browser. It offers 52 diagram types, each in minimal light, minimal dark and full-editorial variants, including architecture, sequence, ER, timeline and Sankey. It can also redraw existing draw.io, Mermaid, Excalidraw and PlantUML files.

💡 Why it matters to you: Architecture and sequence diagrams for a Spring microservices or RAG tutorial take a long time by hand. This gives clean, on-brand versions you can export to SVG or PNG for thumbnails and slides.
Read deeper

You can onboard it to your website so diagrams use your brand's colours and fonts. The README's own example prompt is: "Make me an architecture diagram of my app: frontend, backend, database, Redis cache."

Because the output is one HTML file, it is easy to keep in a Git repo next to the code it describes. Review the generated diagram for accuracy; an agent can draw a plausible arrow that is wrong.

# Any Agent Skills host
npx skills add cathrynlavery/diagram-design

# Claude Code
/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design

Tool: Spring AI Playground, a desktop app to build, test and publish MCP tools with human-in-the-loop approval

GitHub, spring-ai-community/spring-ai-playground · about 147 stars, Apache-2.0

A cross-platform app for building tools as JavaScript, test-running them with sample inputs and publishing them to a built-in MCP server at /mcp for Claude Desktop, Claude Code, Cursor and other clients. It adds agentic chat with RAG, a vector database view, per-tool risk levels L0 to L5 and local observability for tokens, cost and traces.

💡 Why it matters to you: It is a Spring-based way to try the full MCP loop (author, test, publish, call) on your laptop with Ollama or OpenAI, which makes a good base for a tutorial.
Read deeper

A tool must pass a local test run before it is exposed to agents. Shipyard exports validated tools and knowledge as standalone MCP server bundles for Docker. The docs say the sandbox is defence in depth and not adversarial-grade isolation, so do not run untrusted tool code in it.

The project is small (147 stars) and accepts bug reports and documentation fixes but not outside code pull requests for now. The next planned milestone is 1.0.0.

  ghcr.io/spring-ai-community/spring-ai-playground

GitHub repos of the day

Repo: spring-ai-community/mcp-security, OAuth 2.0 and API-key security for Spring AI MCP servers and clients (v0.1.14)

GitHub, spring-ai-community/mcp-security · updated Nov 27, 2026 · Apache-2.0 (not an official Spring or MCP project)

Adds an OAuth 2.0 resource server with JWTs, plus API keys, for MCP servers on Spring WebMVC. The client supports authorization_code, client_credentials and hybrid flows with Dynamic Client Registration, Client ID Metadata Documents and scope step-up. There is also an authorization server that extends Spring Authorization Server for MCP.

💡 Why it matters to you: After this week's run of MCP server CVEs, this is the Java answer to "how do I put real auth in front of my MCP server". It fits a Spring Security and JWT background directly.
Read deeper

Version 0.1.x works only with the Spring AI 2.0.x branch; for Spring AI 1.1.x use 0.0.6. Limits: the deprecated SSE transport is not supported on the server, opaque tokens are not supported (use JWTs), and WebFlux servers get origin validation only, not OAuth2 or API keys.

spring.ai.mcp.server.name=my-cool-mcp-server
spring.ai.mcp.server.protocol=STREAMABLE
spring.security.oauth2.resourceserver.jwt.issuer-uri=http://localhost:9000

Repo: jingyaogong/minimind, train a 64M-parameter LLM from scratch in about two hours (about 72.2k stars)

GitHub, jingyaogong/minimind · Apache-2.0

MiniMind implements the full small-LLM pipeline in native PyTorch: data cleaning, pretraining, SFT, LoRA, DPO, RLAIF with PPO, GRPO and CISPO, tool use, agentic RL, adaptive thinking and distillation. The "2 hours" is the measured time for one SFT epoch on a single NVIDIA 3090, at about 3 RMB of rented compute.

💡 Why it matters to you: If you teach AI engineering, reading a small, from-scratch implementation explains what Ollama and Unsloth are doing underneath. It is a strong base for a "build an LLM" series.
Read deeper

The README's estimate table gives about 2.31 hours and about 3.0 RMB for the dense model with mini pretraining and SFT data, and about 3.23 hours and 4.2 RMB for the MoE variant. The model is tiny, so expect toy-quality answers; the value is in the code and the pipeline.

Project ideas of the day

Idea: an MCP security gateway in Spring Boot, with a React admin console

Project idea · inspired by this week's MCP advisories and the spring-ai-community/mcp-security project

Build a Spring Boot gateway that sits in front of any third-party MCP server and enforces what the servers themselves forgot: OAuth or API-key auth, Host and Origin checks, an SSRF blocklist for private and metadata IPs, per-tool allowlists and an audit log. A React console shows blocked calls and lets you approve a tool once.

💡 Why it matters to you: It combines Spring Security, JWT and React, and it answers a problem that was in the news all week. It is also a tutorial series with a clear before and after: attack an unprotected server, then block it.
Read deeper

MVP in a weekend: a reverse proxy that speaks Streamable HTTP, a JWT filter using Spring Security, and a table of allowed tools in Postgres. Demo against the kinds of flaws in the advisories: a tool that fetches a URL, a route with no auth and a "read-only" tool that can run SQL.

Stretch goals: a policy file in the repo, a dry-run mode that only logs, and a Decision-style classifier for suspicious tool arguments.

  • Original: mcp-security
  • Related: GHSA-mqxc-j2ww-xfvx (an SSRF example)

Idea: a pull-request policy bot with an observe-only mode, built on Spring AI and a GitHub App

Project idea · inspired by Claude Ship and Claude Approvals

Write a GitHub App in Spring Boot that reads a policy file from the repo, classifies each pull request with an LLM judge (docs only, dependency bump, risky change) and records what it would approve. Start in observe-only mode, then post a check run once the team trusts it. A React dashboard shows agreement between the bot and human reviewers.

💡 Why it matters to you: It uses your Spring Boot and React skills on a real developer-tool problem, and the observe-first pattern is the same one Anthropic recommends for its own approvals feature.
Read deeper

Core pieces: a webhook endpoint, a policy parser, a judge that returns a score plus reasons, and a store of decisions. The most valuable part for a demo is the agreement chart over a few weeks of real PRs.

Keep it from approving anything by default. A bot that only comments is safe to ship first.

  • Original: Introducing Claude Ship

Idea: an AI assistant for Indian merchants that explains UPI MDR and RBI rules, with RAG over official circulars

Project idea · inspired by the UPI MDR and RBI payment-aggregator changes

Build a RAG chatbot that answers merchant questions such as "what is the MDR on a Rs 5,000 UPI payment?" using retrieved text from NPCI and RBI circulars, with a citation to the paragraph. Add a calculator for the fees and a Razorpay checkout sandbox demo so the answer connects to a real integration.

💡 Why it matters to you: It fits your India focus and your Spring AI and pgvector skills, and the cited-answer design is the right pattern for regulated topics.
Read deeper

The search results this week mention a 0.4% MDR above Rs 2,000 from Oct 15 and a Dec 31, 2026 market-share cap deadline, but those are secondary sources, so the first job of the project is to ingest the official circulars and compare. Refuse to answer when retrieval finds nothing.

Add an eval set of 50 questions with known answers, and run it with Promptfoo so that a model or prompt change cannot silently break correctness.

Learn this today

Learn today: write one SKILL.md and load the same skill in two agents

Hands-on exercise · about 30 minutes · based on the Agent Skills standard

An Agent Skill is a folder with a SKILL.md file (YAML front-matter plus instructions) and optional scripts and reference files. Write a small skill for something you do often, such as "review a Spring Boot controller for validation and error handling", then use it in Claude Code and in a Spring AI app through the SkillsTool from spring-ai-agent-utils.

💡 Why it matters to you: Over 70 platforms now read this format, so one skill file serves your editor, your CLI agent and your Java app. Writing a good description is the main skill to practise.
Read deeper

Steps: (1) create the folder and file below, (2) put it in the skills directory your agent reads, (3) ask a question that should trigger it and confirm that the agent loads it, (4) point the SkillsTool at the same folder in a Spring AI sample. Check each tool's README for the exact skills directory, since I have not verified the paths.

Make the description specific about when to use the skill. Vague descriptions are the usual reason an agent does not pick a skill up.

spring-controller-review/
  SKILL.md

---
name: spring-controller-review
description: Review a Spring Boot REST controller for validation, error handling and status codes. Use when asked to review or harden a controller.
---
1. Check every request body has @Valid and constraints.
2. Check errors go through @ControllerAdvice, not stack traces.
3. Check status codes: 201 on create, 404 on missing, 409 on conflict.
4. Report findings as a short checklist with file and line.
