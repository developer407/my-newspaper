🛠️ AI tools of the day

Tool: last30days-skill — an agent skill that researches any topic across the last 30 days

mvanhorn/last30days-skill · ≈68k stars, MIT

Give it a topic (a company, a product, “X vs Y”) and it finds handles, repos and subreddits, searches many sources in parallel (Reddit, Hacker News, GitHub, YouTube transcripts, arXiv, Polymarket and more), scores results by engagement, relevance and freshness and returns a cited brief. Reddit, Hacker News, Polymarket and GitHub work with no configuration.

💡 Why it matters to you: It is the fastest way to research a video topic or compare two frameworks before you record: “Spring AI vs LangChain4j, last 30 days”.
Read deeper

Install in Claude Code with /plugin marketplace add mvanhorn/last30days-skill then /plugin install last30days; for other agents use npx skills add mvanhorn/last30days-skill -g. Some sources need API keys or opt-in flags. The scoring favours engagement, so check that a popular answer is also a correct one.

/plugin marketplace add mvanhorn/last30days-skill
/last30days Spring AI vs LangChain4j

Tool: ffmpeg-skill — 42 local FFmpeg tools and an MCP server for editing video with a coding agent

kajisho5/ffmpeg-skill · ≈6.9k stars, MIT

A local video editing toolkit for Claude Code, Cursor, Codex and any MCP client. Its 42 tools cover analysis (probe, scene detection, contact sheets), editing (cut, join, silence removal, crop, stabilise), audio clean-up and loudness, captions, platform exports and batch rendering from a project file. Every tool supports --dry-run and --json, and nothing leaves your machine.

💡 Why it matters to you: You make tutorial videos: silence removal, loudness normalisation and vertical Shorts exports are the repetitive parts of editing.
Read deeper

The MCP server advertises a core set of 12 tools to keep client context small; set FFMPEG_SKILL_MCP_FULL=1 for all 42. Requires FFmpeg 6.1+ and Python 3.10+, and local captions need a separate engine such as faster-whisper. Run npx ffmpeg-skill doctor to check the set-up.

npx ffmpeg-skill          # install for Claude Code
npx ffmpeg-skill doctor   # verify FFmpeg and components

Repo: ag-ui-protocol/ag-ui — an open protocol that connects any agent to any frontend (≈19k★, MIT)

ag-ui-protocol/ag-ui · trending, Nov 16, 2026 (+791 stars that day)

AG-UI standardises how an agent talks to a UI: streaming chat, tool calls mid-response, shared state through snapshots and JSON Patch deltas, human-in-the-loop interrupts, reasoning display and generative UI, as 31 event types over HTTP + SSE or Protobuf. Integrations include LangChain, CrewAI, Google ADK, Mastra, Pydantic AI, LlamaIndex, the OpenAI Agents SDK and Spring AI.

💡 Why it matters to you: It is the missing piece between your Spring AI backend and your React chat UI, and a ready-made tutorial subject.
Read deeper

Scaffold a frontend with npx create-ag-ui-app@latest. SDKs exist for TypeScript, Python and .NET; the page lists Spring AI among supported integrations. Created by CopilotKit; about 5,480 commits at the time of the snapshot.

npx create-ag-ui-app@latest

Repo: spring-ai-community/mcp-security — OAuth 2.0, API keys and DNS-rebinding checks for MCP in Spring (0.1.14)

spring-ai-community/mcp-security · updated Nov 16, 2026 (≈123★, Apache-2.0)

Modules for an MCP server (OAuth 2.0 resource server, API-key auth, Origin and Host validation), an MCP client (authorization_code, client_credentials, hybrid, Dynamic Client Registration, CIMD, scope step-up) and an MCP authorization server built on Spring Authorization Server. Current release 0.1.14 works with Spring AI 2.0.x; 0.0.6 is for 1.1.x.

💡 Why it matters to you: Today’s security paper has an MCP command-injection CVE; this is how you put auth in front of your own Spring MCP server.
Read deeper

Setting the issuer URI is enough for the Boot module to create a default filter chain that secures all endpoints. Limitations: no SSE transport or opaque tokens on the server, and OAuth2 and API-key auth require WebMVC.

spring.ai.mcp.server.protocol=STREAMABLE
spring.security.oauth2.resourceserver.jwt.issuer-uri=http://localhost:9000

💡 Project ideas of the day

Idea: “Spring AI agent cockpit” — a React UI with live tool calls and approvals over AG-UI

Project idea · built from today’s AG-UI repo, Spring AI 2.1 RC2 and Claude Code permission changes

Build a Spring Boot agent with two or three tools (search, send email, create ticket) and an AG-UI event stream feeding a React app that shows tool calls as they stream, a shared-state side panel and an approve/deny prompt before risky tools. Spring AI 2.1 RC2 now streams partial tool-call arguments, which is exactly what such a UI renders.

💡 Why it matters to you: It is a portfolio piece that shows human-in-the-loop design, the thing hiring managers for agent roles ask about.
Read deeper

Stack: Spring Boot 4.2, Spring AI 2.1 (tool-call confirmation arrives in 2.1.0-RC1), Postgres for session memory, React + the AG-UI client. Tutorial split: backend tools, event stream, approval UI, then deploy with Docker Compose. Add Langfuse traces for an eval chapter.

Idea: an MCP “bouncer” gateway — scan, allow-list and log every tool call to your MCP servers

Project idea · built from the code-review-mcp-server CVE and spring-ai-community/mcp-security

A small Spring Boot gateway that sits between an agent and its MCP servers: it applies an allow-list of tools, checks argument patterns (no shell metacharacters in path or branch parameters), enforces OAuth scopes with mcp-security and writes an audit log that a React dashboard can search.

💡 Why it matters to you: MCP security is a live topic with real CVEs and few polished tutorials, so it is good content and a good portfolio piece.
Read deeper

MVP: proxy Streamable HTTP, block calls that match a regex, store allowed and denied calls in Postgres. Stretch: scan an MCP server’s tool descriptions for hidden instructions and flag changes between versions.

📚 Learn this today

Learn today: never build a shell command or file path from model output — Java edition

Concept · inspired by this week’s CVEs (code-review-mcp-server command injection, zt-zip Zip Slip)

Two advisories in this edition share a cause: untrusted text reached a shell or a filesystem path. In Java, use ProcessBuilder with an argument list (never sh -c with concatenation) and normalise paths then check they stay inside an allowed root. This applies to LLM tool arguments exactly as to user input.

💡 Why it matters to you: Every Spring AI @Tool method you write is an injection point: the model decides the arguments, and a prompt injection can decide for the model.
Read deeper

Checklist for a tool method: 1) validate types and lengths, 2) resolve and normalise any path, compare with the allowed root, 3) call programs with an argument array, never through a shell, 4) run with least privilege, 5) log arguments and results. The snippet below shows items 2 and 3.

Path root = Path.of("/data/workspace").toRealPath();
Path p = root.resolve(userPath).normalize();
if (!p.startsWith(root)) throw new SecurityException("outside workspace");
new ProcessBuilder("git", "diff", "--", p.toString()).start();
